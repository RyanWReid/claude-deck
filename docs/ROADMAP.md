# Roadmap

## Shipped
- **v0.4** One persistent Claude Code session; approval cards; modes; model picker; usage meters; Markdown replies; phone handoff
- **v0.5** Redesign: themes, icon set, grouped steps; Look & ask; spoken replies
- **v0.6** Hold to ask from anywhere, with a caption over the game
- **v0.7** Ask Claude on game pages; dictation; crash and screenshot help; game notes; background jobs; rebindable shortcuts
- **v0.8** Speech starts while the reply streams; faster transcription
- **v0.9** First-run setup and in-place updates; chats and a chat per game; save backups; low-battery help

## Next
- Multilingual voice (Whisper multilingual model, more Piper voices) and a voice picker
- A faster model for spoken questions (Sonnet/Haiku for voice, the main model for typed)
- Wake-free "continue": hold to ask follow-ups without repeating context
- Library unifier: Epic/GOG/Heroic games as Steam shortcuts with artwork
- Storage janitor: shader caches, orphaned Proton prefixes, unused runtimes
- Per-game performance memory that's applied when the game launches
- Localization of the UI
